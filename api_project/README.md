# Book Management API

A lightweight RESTful API built with Django and Django REST Framework (DRF) for managing a book collection. This project demonstrates CRUD operations, Token Authentication, and permission handling.

## 🚀 Features
* **Full CRUD**: Create, Read, Update, and Delete books.
* **Token Authentication**: Secure access using DRF's Authtoken system.
* **Smart Permissions**: Public users can view books; only authenticated users can modify them.
* **Browsable API**: Interactive web interface for testing.
